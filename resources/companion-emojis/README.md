# Companion emoji artwork

These SVG files are a focused subset of Google Noto Emoji used by the
DeskThing Companion to render ilyStream's supported TikTok shortcodes without
depending on the device's system emoji font.

Source: https://github.com/googlefonts/noto-emoji/tree/8998f5dd683424a73e2314a8c1f1e359c19e8742/svg
